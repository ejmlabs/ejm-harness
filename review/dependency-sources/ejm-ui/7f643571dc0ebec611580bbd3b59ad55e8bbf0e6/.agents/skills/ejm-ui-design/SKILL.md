# Shared design

Read [the quality bar](../../../QUALITY.md) and the affected package's public
guide before choosing a pattern. Use public shared components and recipes.
Extend the shared owner when a pattern is missing; consumers supply content and
state, without a separate visual system.

## Content

Default to a clear visual or no added content. Use only the words needed to
understand the task, choose safely and recover. Keep meaningful labels,
accessible names, consent and security facts, and honest state. Avoid cryptic
icons and meaning conveyed only by color. Apply [the content quality rule](../../../QUALITY.md#content),
show supporting detail when needed, and keep operational docs complete.

Review the actual flow: remove repeated explanations, keep the current task
clear, and check keyboard access and assistive names after reducing visible
copy. Do not add word-count gates or tests that match incidental wording.
